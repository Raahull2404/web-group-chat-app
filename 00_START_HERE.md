## 🚀 How to Use

### Quick Start (5 minutes)
```bash
# 1. Install dependencies
npm install && cd client && npm install && cd ..

# 2. Configure environment
cp .env.example .env

# 3. Start backend (Terminal 1)
npm run dev

# 4. Start frontend (Terminal 2)
cd client && npm start

# 5. Open browser
http://localhost:3000
```
