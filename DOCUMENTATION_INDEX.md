## 📞 Quick Reference

### Commands
```bash
# Backend
npm install
npm run dev
npm start

# Frontend
cd client
npm install
npm start

# Database
mongod
```

### URLs
- Frontend: http://localhost:3000
- Backend: http://localhost:5000
- MongoDB: mongodb://localhost:27017

### Key Files
- Backend: `server.js`
- Frontend: `client/src/App.js`
- Components: `client/src/components/`
- Styles: `client/src/styles/`
